# RALWebExample

Exemplo simples de um sistema web através do PascalRAL, mostrando navegação entre a tela inicial de login (login.html) e uma tela principal (main.html)

Necessário uma pasta "web" com os 2 arquivos .html no mesmo diretório da aplicação compilada

 - Copie a pasta "web" para dentro da pasta da aplicação compilada para poder executar o exemplo
