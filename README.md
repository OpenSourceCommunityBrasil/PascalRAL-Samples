# PascalRAL-Samples
Exemplos de uso do projeto PascalRAL

O branch `2.0` acompanha o RAL 2.0: nele os servidores ligam plugins
(`TRALCompressPlugin`, `TRALCriptoPlugin`, `TRALCORSPlugin`...) no lugar das
propriedades que o `TRALServer` perdeu (`CompressType`, `CriptoOptions`,
`CORSOptions`, `Security`), e os projetos do Lazarus exigem os pacotes com os
nomes da 2.0. O `dev` continua no RAL 1.x.
